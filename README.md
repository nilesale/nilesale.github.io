# نيل سيل | Nile Sale

سوق مصر للإعلانات والمزادات: سيارات، دراجات نارية، عقارات، أراضي، عقارات تجارية، نمر سيارات، نمر موبايلات، موبايلات، إكسسوارات جيمنج، ساعات وغيرها.

## وش اللي يشتغل في هذي النسخة
- تصفّح الأقسام والفلاتر وصفحات الإعلانات، بالعربي والإنجليزي.
- نشر إعلان بسعر ثابت أو مزاد، مع الصور.
- لوقوات وكالات السيارات والدراجات.
- تثبيت الموقع على الجوال كتطبيق، ويفتح بدون إنترنت بعد أول زيارة.

## حدود هذي النسخة (مهم)
- البيانات تنحفظ في متصفح كل زائر على جهازه. الإعلان اللي تنشره يشوفه نفس الجهاز بس، ما يشوفه غيرك.
- تسجيل الدخول برقم الجوال تجريبي. جوجل وآبل يصيرون حقيقيين بعد إعداد سوبابيس (تحت).
- الدفع (تمييز الإعلان ورسوم المزاد) تجريبي، ما ينسحب أي مبلغ.
- الترجمة التلقائية وتقدير السعر الجديد متوقفة برا كلود.

الخطوة الجاية: ربط قاعدة بيانات مشتركة (سوبابيس) مكان الملف `js/backend.js`، بنفس طريقة الاستخدام، عشان الإعلانات والحسابات تصير مشتركة بين كل الناس.

## تسجيل الدخول عبر جوجل وآبل
الكود جاهز ويشتغل عن طريق سوبابيس. عشان يتفعّل:
1. حط رابط مشروع سوبابيس ومفتاحه العام في `js/config.js`.
2. فعّل جوجل وآبل في سوبابيس (Authentication ← Sign In / Providers).
3. في `js/config.js` خلّ المزوّد اللي فعّلته على `true`.

لين ما تنحط القيم، يبقى تسجيل الدخول تجريبي مثل قبل.

## ملفات المشروع
| الملف | وظيفته |
|---|---|
| `index.html` | الموقع كامل: التصميم والشاشات والأقسام |
| `js/backend.js` | تخزين البيانات (حالياً في متصفح الزائر) وتسجيل الدخول |
| `js/config.js` | إعدادات سوبابيس ومزوّدي تسجيل الدخول |
| `js/vendor/` | مكتبة سوبابيس |
| `data/seed.json` | الإعلانات التجريبية وربط اللوقوات |
| `logos/` | لوقوات السيارات والدراجات |
| `media/` | صور الإعلانات التجريبية |
| `manifest.webmanifest`, `sw.js`, `icons/` | ملفات تطبيق الجوال |

## التشغيل على جهازك
افتح مجلد المشروع وشغّل:

```
python3 -m http.server 8000
```

وبعدها افتح `http://localhost:8000` في المتصفح.
